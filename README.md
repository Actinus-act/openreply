## 💡 این پروژه چیست؟

بسیاری از صفحات اینستاگرامی از مخاطبان می‌خواهند کلمه‌ای مثل «لینک»، «قیمت» یا «تخفیف» را زیر پست‌ها کامنت کنند تا اطلاعات برایشان ارسال شود. ابزارهایی مانند ManyChat برای این کار هزینه‌های سنگین دلاری و محدودیت در تعداد پیام دارند.

**OpenReply** یک سیستم مستقل، ایمن و متن‌باز است که روی سرور شخصی شما مستقر می‌شود و به شما اجازه می‌دهد سناریوهای نامحدود دایرکت هوشمند بسازید.

## ✨ قابلیت‌های اختصاصی این نسخه (بروزرسانی‌شده):

* 📸 **ارسال تصویر در دایرکت (DM Image Support):**
  * امکان آپلود و ارسال خودکار عکس به عنوان Attachment در دایرکت (قابلیتی که در نسخهٔ اصلی پروژه وجود نداشت).
* 🎯 **پشتیبانی از چند پست در یک کمپین (Multi-Post Targeting):**
  * برخلاف نسخهٔ خام که برای هر پست باید یک کمپین مجزا تعریف می‌شد، در این نسخه می‌توانید **چندین پست یا ریلز را هم‌زمان برای یک سناریوی دایرکت انتخاب کنید**.
* 🇮🇷 **پشتیبانی بومی از زبان فارسی:**
  * پشتیبانی از کاراکترها و جداکنندهٔ ویرگول فارسی («،») در کلمات کلیدی.
  * برطرف شدن باگ لوپ پاسخ‌های خودکار.
* 🔒 **قفل فالوور (Follow Gate):**
  * شرط فالو داشتن پیج قبل از ارسال لینک (بررسی وضعیت فالو توسط API رسمی متا و ارسال پیام یادآوری در صورت فالو نبودن).
* 💬 **پاسخ عمومی خودکار به کامنت:**
  * درج پاسخ رندوم و خودکار زیر کامنت کاربر به‌صورت هم‌زمان با ارسال دایرکت.
* 🔗 **دکمه‌های شیشه‌ای و ردیابی کلیک (Tracked Links):**
  * ساخت دکمه‌های اختصاصی اینستاگرام با آمار دقیق کلیک‌ها و نرخ تبدیل (CTR).
* 🛡️ **امنیت ۱۰۰٪ و ضد بلاک:**
  * اتصال از طریق Meta Graph API یا رابط اختصاصی Zernio.
  * هیچ پسوردی از پیج شما دریافت نمی‌شود و ارسال‌ها طبق ریت‌لیمیت استاندارد اینستاگرام (صف‌بندی در Redis) انجام می‌گردد.

## 🛠️ ساختار فنی و پیش‌نیازها

* **فریم‌ورک:** Next.js 16 + React 19 + TypeScript
* **دیتابیس و ORM:** PostgreSQL + Prisma 7 (دارای ایندکس‌های اختصاصی GIN)
* **مدیریت صف و ورکر:** Redis 7 + BullMQ
* **وب سرور و پروکسی:** Caddy یا Nginx با SSL خودکار

## 🚀 راهنمای سریع راه‌اندازی با داکر (Docker Compose)

ساده‌ترین روش برای اجرای شخصی پروژه استفاده از Docker است:

```bash
# ۱. کلون کردن مخزن
git clone https://github.com/Actinus-act/openreply.git
cd openreply

# ۲. ایجاد فایل تنظیمات
cp .env.example .env
# مقادیر مربوط به دامنه و دیتابیس را در .env تنظیم کنید

# ۳. اجرای سرویس‌ها
docker compose -f docker-compose.prod.yml --profile caddy up -d --build
```

### اجرای در محیط توسعه (Local Development):

```bash
npm install
npm run db:generate
npm run db:migrate
npm run dev      # سرور وب روی پورت 3000
npm run worker   # ورکر ارسال پیام‌ها در ترمینال دوم
```
